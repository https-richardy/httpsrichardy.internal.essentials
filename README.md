# HttpsRichardy.Internal.Essentials

**HttpsRichardy.Internal.Essentials** is a shared core package for https-richardy projects, providing essential abstractions, patterns, and utilities. It serves as a reusable foundation that accelerates development and standardizes practices across APIs.

---

## Purpose

- Centralize essential patterns and structures.
- Avoid code duplication across multiple projects.
- Provide a reliable foundation for new APIs.
- Ensure consistency in errors, value objects, filters, and utilities.

---

## Installation

You can install it via NuGet (internal package):

```bash
dotnet add package HttpsRichardy.Internal.Essentials
```
